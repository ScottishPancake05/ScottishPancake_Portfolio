Vice Shooter

Shoot the beans to win!

---
Vice Shooter was my very first 3D game made in Unity. This project was a massive learning experience where I learned the basics of Unity 3D. Through making this game, I learned how to use Scriptable Objects, set up enemy pathfinding using the AI NavMesh and build custom spawners to keep the enemies coming!

Working on this project was the main reason I later started Vice Noire as a personal project, which is also a First-Person Shooter.

Genre: First Person Shooter

Platform: PC

Status: Finished demo

Engine: Unity

Year: 2023
